# SABERO AI Sales Engine Frontend

Panel administrativo independiente del backend NestJS.

## Desarrollo

```bash
npm install
npm run dev
```

URL local:

```text
http://127.0.0.1:5173
```

API esperada:

```text
http://localhost:3001/api/v1
```

## Vistas

- Resumen
- Conocimiento
- Agente
- Canales
- Operaciones

Este frontend no contiene logica del agente. Solo configura y opera el producto via API.
